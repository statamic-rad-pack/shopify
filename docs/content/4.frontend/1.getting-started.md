As we are pulling all our products into Statamic, we'll want a way to let customers actually buy them. There are two ways to handle that on the front-end, and picking the right one up front will save you some rework later.

## Which option should I use?

| | Storefront API | Buy Buttons |
|---|---|---|
| Setup effort | More — you build the cart/checkout flow | Least — paste in embed code |
| Customisation | Full control over cart, styling and checkout flow | Limited to what Shopify's widget offers |
| Best for | Stores with more than a handful of products, or where the cart/checkout needs to match your site's design | A small number of products where an out-of-the-box "Buy" button is good enough |
| Supported by this addon | Yes — see below | No, it's just embedded HTML |

If you're not sure, start with the Storefront API. It's the option this addon is built around, and the example templates below get you most of the way there without much extra work.

## Storefront API

The [Storefront API](https://github.com/Shopify/shopify-app-js/tree/main/packages/api-clients/storefront-api-client#readme) gives you full control over the buying experience by letting you talk to Shopify directly from your own JavaScript. This addon provides the tags, scripts and example templates to handle three things:

1. Creating a cart instance and remembering it across pages
2. Handling adding products from our CMS to the cart
3. Handling the cart overview page and handing that off to Shopify for checkout

A more detailed, method-by-method breakdown of `client.js`, `cart.js` and `alpine.js` can be found on the [Storefront API](/frontend/storefront-api) page — this section is a quick-start checklist to get everything wired up.

### 1. Install the Storefront API client

The addon's `client.js` depends on Shopify's own JS client. Add it to your `package.json`:

::code-group

```bash [Yarn]
yarn add @shopify/storefront-api-client
```

```bash [NPM]
npm install @shopify/storefront-api-client --save
```

::

### 2. Publish the scripts and example templates

The addon ships uncompiled JS (`client.js`, `cart.js`, `alpine.js`) and example `antlers` templates for the `cart`, `product` and `products` pages. Publish both:

```bash
php artisan vendor:publish --tag="shopify-scripts"
php artisan vendor:publish --tag="shopify-theme"
```

This puts the JS in `resources/js/vendor/shopify` and the templates in `resources/views/vendor/shopify`, so you can edit either freely.

### 3. Add the tokens tag to your layout

`client.js` needs to know your store's URL and Storefront API token before it can connect. The [`{{ shopify:tokens }}` tag](/frontend/tags#tokens) outputs a small `<script>` block that puts these on `window.shopifyConfig`, which `client.js` reads when it initialises.

Add it to your layout's `<head>`, above where you load your compiled `site.js` (using `@vite` if you're on the default Statamic starter kit):

```antlers
{{ shopify:tokens }}
@vite('resources/js/site.js')
```

Without this tag, `client.js` has nothing to connect to and will error as soon as it's imported.

### 4. Wire the scripts into `site.js`

Import and start Alpine, and register the Shopify store/data helpers, in your `resources/js/site.js`:

```js
import { createData, createStore } from './vendor/shopify/alpine';
import Alpine from 'alpinejs';

window.Alpine = Alpine;

createStore(Alpine);
createData(Alpine);

Alpine.start();
```

Anywhere you need to talk to the API directly (rather than through the Alpine helpers), import the client:

```js
import client from 'vendor/shopify/client';
```

`cart.js`'s methods (creating a cart, adding lines, updating quantities, and so on) are covered in full on the [Storefront API](/frontend/storefront-api) page.

### 5. Finish the setup

You'll also need to set up the corresponding pages in the CP, update your `config/shopify.php`, and pull down your products before everything clicks together — see [Installation](/installation) if you haven't done that yet.

## Buy Buttons

[Buy Buttons](https://www.shopify.co.uk/buy-button) are Shopify's own out-of-the-box embeds, and work best if you have a small number of products and don't need much customisation.

They're set up per product in the Shopify admin, which generates some embeddable HTML you can paste into a custom field on the entry to output on the frontend.

Buy Buttons live entirely outside of this addon — there's no integration to configure, so once you've pasted the embed code in, you're done.
